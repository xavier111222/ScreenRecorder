# 屏幕录制器（ScreenRecorder）

[简体中文](README.md) | [English](README_EN.md)

一个 **独立单文件** 的 Windows 录屏小工具：全屏或任意区域录制，输出标准的
**MP4（H.264）** 文件，可直接发微信 / 上传 / 剪辑。

- 单文件 exe，绿色免安装（**内置 ffmpeg，无需另外安装**）
- 开源协议：**MIT**
- 全程本地录制，不联网上传
- 完整支持高 DPI（150% / 200% 缩放）

## 快速开始

1. 双击 **`屏幕录制器.exe`**
2. 选「全屏」或点 **「框选区域」** 拖拽要录的范围
3. 点 **「● 开始录制」**（或按 **F9**）→ 倒计时后自动开录，窗口自动最小化
4. 结束：再按 **F9** 或点「停止录制」，文件自动保存到输出目录

下载地址：<https://github.com/xavier111222/ScreenRecorder/releases/latest>

## 功能一览

### 四种录制区域

不只是「全屏」和「手动画框」，还可以按应用窗口录，或让程序自动识别内容区：

| 模式 | 说明 |
| --- | --- |
| **全屏** | 整个虚拟桌面（含多显示器） |
| **框选区域** | 拖拽自选，区域选择器带模糊底图，所见即所得 |
| **应用窗口** | 从窗口列表挑一个程序直接录它的窗口，**录制中可跟随窗口移动/缩放** |
| **自动识别** | 自动分析当前画面，裁掉黑边 / 纯色边框，框出真实内容区 |

> **「跟随移动」**是录屏里最实用的功能：你在录制的同时用鼠标拖动目标窗口，
> 取景会自动跟着变。因为 ffmpeg 的输入尺寸在启动时固定，尺寸一变就自动
> 分段续录，最后无缝拼接成一个文件（`-c copy` 无损合并，音频同步）。
> 只移动位置、尺寸没变时则完全不打断录制。

### 录制建议

| 用途 | 推荐设置 |
| --- | --- |
| 演示操作 | 区域框选 + 30fps + 中画质 + 显示指针 |
| 录制游戏 | 全屏 + 60fps + 高画质（体积会大很多） |
| 只讲思路 | 24fps + 高（快编码），体积最小 |
| 需要声音 | 先在 Windows 声音设置里允许桌面应用播放音频，再刷新设备列表 |

## 它是怎么工作的？

1. **抓屏**：`mss`（GDI `BitBlt` + 多线程），一帧约 8ms，1920×1080@30fps 完全跑得动。
2. **编码**：把 BGRA 原始帧直接写进 `ffmpeg` 子进程的 stdin：
   ```
   ffmpeg -f rawvideo -pix_fmt bgra -s WxH -framerate FPS -i -
          -c:v libx264 -preset veryfast -crf N -pix_fmt yuv420p out.mp4
   ```
   `yuv420p` 保证在手机、微信、剪映里都能正常播放。
3. **节拍**：与连点器同一套 `next += interval` 调度，帧率稳定不累积漂移；
   落后超过 1 秒自动重新对时。
4. **鼠标指针**：抓屏拿到的是不带光标的画面，需要的话在内存里画一个再送编码。
5. **UI**：录制在后台线程，界面只负责显示状态；线程消息经队列回主线程
   （Tk 不是线程安全的，直接 `root.after` 会偶发崩溃）。

## ⚠ 注意事项

1. **录不到受保护内容**：DRM/加密视频（Netflix、爱奇艺等）播放时会黑屏或空白，
   这是所有屏幕录制工具的共同限制，本工具不做也不建议做破解。
2. 体积估算：1080p 30fps 中画质约 **6–10 MB/分钟**；60fps 约为 1.5–2 倍。
   磁盘空间不足会导致录制中断。
3. 录的是整个显示器内容，请注意隐私，**不要在不合适的场合录制他人画面**。
4. 首次运行被 SmartScreen 拦截时，点「更多信息 → 仍要运行」（未签名开源程序常见）。
5. 内置 ffmpeg 为第三方静态构建（GPL/LGPL），作为独立进程调用、未修改其代码。

## 从源码运行与构建

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt

python screen_recorder.py            :: 直接运行源码
.venv\Scripts\python build.py        :: 生成图标 → PyInstaller（含 ffmpeg）→ 复制到桌面
```

> 打包时 ffmpeg 二进制会一并塞进 exe（构建产物约 40–60 MB，属正常）。

## 常见问题

**Q：点开始录制提示「未找到 ffmpeg」？**
A：正常情况下 exe 已内置。若你改过打包流程，可把 `ffmpeg.exe` 放到 exe 同目录，
或安装 ffmpeg 并加入 PATH，然后 `--selftest` 确认。

**Q：录出来文件打不开 / 只有声音？**
A：分辨率必须是偶数（程序已自动向下取偶）；若显卡占用高导致掉帧，
可降低帧率或缩小录制区域。

**Q：录不到系统声音？**
A：Windows 声音设置里没开"允许桌面应用播放音频"时不会有对应设备；
开启后点「刷新设备」。

**Q：录制时很卡？**
A：抓屏 + 编码都吃 CPU。可把帧率降到 24、画质选"高（快编码）"，
或只录窗口区域而非全屏。
